# 第一部分：数学 Mathematics（英文卷）

## A. 二次方程与韦达定理 Quadratics & Vieta's　【保命模块，务必全 ✅】

- [ ] `基` 已知一个根，代入求参数（含无理系数如 √7）—— *例：√7·mx²−m²x−2=0 有一根 x=2，求 m²+m⁻²*
- [ ] `基` 由 α+β、αβ 求对称式的值（Vieta's formulas）
- [ ] `进` **降次法**：用方程本身 α²=2α+2 反复代换，求 α³−2β²+10β 这类高次表达式
- [ ] `进` 含参方程"解的个数"讨论——**记得讨论二次项系数=0 退化成一次方程的情况**（例：dx²−(d−1)x+d=0 恰好一个实根，求 d 的个数）
- [ ] `基` 判别式 Δ 判断根的情况、两根之差/两根平方和等

## B. 函数与复合函数 Functions　【国际课程通常已学，重点是"熟练+快"】

- [ ] `基` 函数记号 f: x ↦ 2x−a，代入求值
- [ ] `进` 复合函数 fg(x)、ff(x)、fff(x)，解 fff(x)=771 这类方程
- [ ] `进` fg(x)=gf(x) 只有一个实数解，用判别式求参数
- [ ] `赛` **函数方程**：(2ˣ)+x·f(2⁻ˣ)=x²+x³ 对任意 x 成立，用 x→−x 代换联立求 f(8)
- [ ] `进` **图象变换**：已知 f(x) 的最大/最小值点，求 y=−2f(3−x) 的最大/最小值点（平移+翻折+伸缩复合）
- [ ] `进` 曲线绕原点旋转 180°（即 (x,y)→(−x,−y)），求参数
- [ ] `基` 反函数 f⁻¹(x)、定义域值域

## C. 坐标几何 Coordinate Geometry　【每卷 2–3 题，稳定得分区】

- [ ] `基` 中点公式、两点距离、菱形/矩形放坐标系求顶点坐标
- [ ] `基` 点关于直线的对称（反射），例：(3,−4) 关于 3x−4y=50 的对称点
- [ ] `进` 原点到直线的最短距离（点到直线距离公式 / 3-4-5 结构）
- [ ] `进` 直线 × 反比例函数 y=k/x 交点、围成三角形面积
- [ ] `进` |AD|=5|BC| 这类由长度比反求坐标
- [ ] `赛` **"将军饮马"对称最值**：x 轴上动点 C，求 AC+BC 最小、|AC−BC| 最大

## D. 代数变形与换元 Algebraic Manipulation　【竞赛味重，拉分关键】

- [ ] `赛` **换元**：令 t=2a+1/a，解 3(4a²+1/a²)+7(2a+1/a)=64
- [ ] `进` 对称式恒等：由 x+y、x³+y³ 求 x²+y²（用 x³+y³=(x+y)³−3xy(x+y)）
- [ ] `赛` 多元对称多项式的因式分解
- [ ] `基` 完全平方、平方差、立方和差公式的灵活运用

## E. 根式 · 数列 · 求和 Surds, Sequences & Series　【区分度题】

- [ ] `基` 分母有理化、比较根式大小、按大小排序
- [ ] `赛` **共轭配对**：求最接近 (√6+√7)⁴ 的整数（用 (√7+√6)ⁿ+(√7−√6)ⁿ 为整数）
- [ ] `赛` **裂项相消**：一长串 1/(√n+√(n²−1)) 求和
- [ ] `进` 等差/等比数列、简单通项与求和

## F. 组合 · 概率 · 数论 Combinatorics, Probability & Number Theory　【最"竞赛"，冲 A/B 必备】

- [ ] `进` 古典概率：随机游走（机器人走 6 步回原点）、正方体两面相对的概率
- [ ] `进` 排列组合 C(n,k)、简单计数
- [ ] `赛` **面积比 / 塞瓦线**：BP=2PC、AQ=3QC，由三角形面积求内部四边形面积
- [ ] `赛` **数论找规律**：多位数中"任意相邻几位构成 7 或 13 的倍数"，靠周期性推末位数字
- [ ] `进` 整除、余数、奇偶性等基础数论

# 第二部分：英语 English

## I. 听力 Listening　【光剑特色，别人家常不考；只播一遍】

- [ ] `基` Section A 对话理解（校园 / 生活场景）
- [ ] `进` Section B 短文 / 讲座理解（学术话题：科普、气候、人物等）
- [ ] `进` 抓关键信息的**速记能力**（语速快、不重播）
- [ ] `进` 适应 IGCSE / ESL / FCE / 雅思 各档听力难度

## II. 语法与词法 Grammar & Usage　【考得偏、细】

- [ ] `基` 时态 & 语态（含较偏时态搭配）
- [ ] `进` 非谓语动词：to do / doing / done / 完成式（to have done）的区分
- [ ] `进` 虚拟语气 & 倒装（Should…, Had…, Were…）
- [ ] `进` 定语从句 / 状语从句 / 名词性从句（where, that, as though, despite vs though）
- [ ] `进` 连词与介词辨析、固定搭配、习惯表达

## III. 词汇 Vocabulary　【硬指标：4500–5000】

- [ ] `基` 高考核心词全部掌握
- [ ] `进` 向雅思核心词过渡（学术、社科、科技类词）
- [ ] `进` 阅读中的生词猜义能力（上下文推断）

## IV. 阅读理解 Reading Comprehension　【占分最大，30 分】

- [ ] `进` 学术长文精读（文化认知、脑科学、叙事文等），对标雅思 5.5–6.0
- [ ] `进` 题型：主旨大意、细节定位、推断、词义、态度
- [ ] `进` 长难句拆解能力

## V. 写作运用 Writing　【翻译 + 句型转换是常客】

- [ ] `进` 汉译英段落翻译（社会话题短文，约 12 分）
- [ ] `基` 句型转换 / 同义改写：主动↔被动、简单句合并、强调句等（约 8 分）
- [ ] `进` （部分年份有）短文写作 / 议论文
