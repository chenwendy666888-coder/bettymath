CROSS-TOPIC PROBLEMS · MULTI-CONCEPT

综合题 · 多考点交汇

光剑真题大量是"一道题跨好几个考点"。这里按交汇类型分 tab，每类给典型题型 + 可折叠的改编同型例题（点标题展开）。

🔗 为什么单开这一板块：任务②扫的 56 题里，纯单考点的很少——真正拉分的压轴几乎都是多考点复合（反比例+相似、圆+切线+勾股+相似、韦达+二次最值、随机游走=计数+概率…）。会单点 ≠ 会综合，所以要专门练"把两三个知识点串起来"。所有例题均 ✅ sympy 验证，为改编同型题（非真题原题，标【同型·卷】）。

Algebra × Geometry

代数 × 几何
最常见的交汇：把函数/方程放到坐标系里，用代数解出交点，再用几何（距离、相似、面积）收尾。
reciprocal function反比例函数 y = k/x
intersection point交点（联立求解）
distance between points两点间距离 √(Δx²+Δy²)
similar triangles相似三角形（对应边成比例）
典型题型 Types
  • 一次函数 × 反比例函数 → 求交点 / 两交点距离同型·A12·E1⑩
  • 直线 × 反比例 → 相似求 k / 求面积同型·B8
  • 坐标 + 四边形（菱形/矩形）→ 求顶点 / 对角线同型·B4
例题 Worked example · 一次×反比例×距离同型·A12
The line y = x − 1 intersects the reciprocal curve y = 6/x at two points. Find the distance between them.
直线 y=x−1 与反比例 y=6/x 交于两点，求这两点间的距离。
① 联立 Set equal: x − 1 = 6/x ⟹ x² − x − 6 = 0
② 解 Solve: (x−3)(x+2)=0 ⟹ x = 3 或 x = −2
③ 求点 Points: (3, 2) 和 (−2, −3)
④ 距离 Distance: √[(3−(−2))² + (2−(−3))²] = √(25+25) = √50
= 5√2 ✅ sympy 验证
交汇点：②是代数（解一元二次），④是几何/勾股（两点距离）。这就是"代数解出坐标，几何收尾"的标准套路。

Geometry × Geometry (Circle)

几何 × 几何（圆综合）
光剑圆的压轴几乎不单考——总是切线 + 勾股 + 相似三件套一起上。
tangent to a circle圆的切线（切点处 ⟂ 半径）
tangent length切线长（PA² = OP² − r²）
perpendicular from centre垂径定理（半径 ⟂ 弦则平分弦）
典型题型 Types
  • 圆外一点求切线长（切线 ⟂ 半径 + 勾股）同型·C8
  • 切线 + 相似 + 垂径 综合求线段同型·E2⑫
  • 正多边形 + 圆 → 面积 / 边长同型·E1八边形
例题 Worked example · 切线长（切线⟂半径+勾股）同型·C8
Circle O has radius 5. P is outside the circle with OP = 13. PA is tangent to the circle at A. Find the tangent length PA.
圆 O 半径为 5，圆外一点 P 满足 OP=13，PA 与圆相切于 A，求切线长 PA。
① 切线性质 Tangent: 切线 ⟂ 半径，故 △OAP 在 A 处为直角三角形（∠OAP = 90°）。
② 勾股 Pythagoras: PA² = OP² − OA² = 13² − 5² = 169 − 25 = 144
PA = 12 ✅ sympy 验证
交汇点：①用的是圆的性质（切线⟂半径），②用的是三角形的勾股。进阶版会再叠一层相似（割线定理），套路一样：先立直角，再勾股/相似。

Algebra × Algebra

代数 × 代数（方程·韦达·对称式）
不给你直接的根，而是用韦达定理拿到"和与积"，再用对称式变形算目标——是英文卷的高频套路。
Vieta's formulas韦达定理：α+β = −b/a，αβ = c/a
symmetric expression对称式（如 α²+β², α³+β³）
identity恒等式 α²+β² = (α+β)² − 2αβ
典型题型 Types
  • 韦达 + 对称式求值（不解方程）同型·B3
  • 韦达 + 二次函数最值（带约束）同型·C10
  • 整体换元 + 对称/轮换因式分解同型·B7·A9
例题 Worked example · 韦达 + 对称式同型·B3
The two roots of x² − 6x + 4 = 0 are α and β (do not solve for them). Find α² + β².
已知 x²−6x+4=0 的两根为 α、β（不必解出），求 α²+β²。
① 韦达 Vieta: α+β = 6，αβ = 4
② 恒等变形 Identity: α²+β² = (α+β)² − 2αβ = 6² − 2·4 = 36 − 8
= 28 ✅ sympy 验证
交汇点：①是方程（韦达），②是代数变形（对称式恒等式）。关键是不去解根，用"和与积"直接算——省时且避免根式。

Algebra × Probability / Counting

代数 × 概率 / 计数
概率题的分母/分子往往要靠排列组合数出来，本质是"先计数、再算概率"。
combinations C(n,k)组合数 C(n,k)=n!/[k!(n−k)!]
equally likely outcomes等可能结果（古典概型）
random walk随机游走（每步 ±1）
典型题型 Types
  • 随机游走：走 n 步回到原点的概率同型·A4
  • 立方体/骰子面 → 计数 + 概率同型·A7
  • 取球（放回/不放回）→ 概率同型·C7
例题 Worked example · 随机游走回原点同型·A4
Starting at the origin on a number line, each step moves +1 or −1 with equal probability. After 4 steps, what is the probability of being back at the origin?
从数轴原点出发，每步等概率地 +1 或 −1，走 4 步后，恰好回到原点的概率是多少？
① 总数 Total: 每步 2 种，4 步共 2⁴ = 16 条路径。
② 计数 Count: 回原点需 2 步 +1、2 步 −1 → 选哪 2 步向右 = C(4,2) = 6 条。
③ 概率 Probability: 6 / 16
= 3/8 ✅ sympy 验证
交汇点：②是计数（组合数 C(4,2)），③是概率（有利÷总数）。C(n,k) 正好接上 P1 里的杨辉三角。

Functions × Transformation

函数 × 变换
复合函数、图象变换、旋转反求参——都是"函数"与"方程/几何变换"的交汇，英文卷 A-Level 味最浓。
composite function复合函数 f(f(x)) / f(g(x))
fixed point不动点 f(x)=x
transformation图象变换（平移/翻折/伸缩/旋转）
典型题型 Types
  • 复合函数 + 解方程（含不动点 f(f(x))=x）同型·B5
  • 图象变换 y = a·f(b−x) + c同型·A6
  • 抛物线旋转 180° 反求参数同型·B6
例题 Worked example · 复合函数 + 解方程同型·B5
Let f(x) = 2x + 1. Find f(f(x)), then solve f(f(x)) = x.
设 f(x)=2x+1。先求 f(f(x))，再解方程 f(f(x))=x。
① 复合 Compose: f(f(x)) = 2·(2x+1) + 1 = 4x + 3
② 解方程 Solve: 4x + 3 = x ⟹ 3x = −3
x = −1 ✅ sympy 验证
交汇点：①是函数（复合运算），②是代数（解一次方程）。真题里 f 常是二次，复合后变成解一元二次——套路不变，只是方程升级。
