二、核心概念 · 别再混淆

代数其实是一层层叠上去的。先分清这几个「长得像」的东西：

Expression代数式
一串数与字母，没有等号，只能化简/求值。
别混：例 3x+2。它不是要你解——是要你算或化简。
Equation方程
含等号 =，只有特定的值使它成立，要你解出未知数。
别混：例 3x+2=8 ⇒ x=2。「解方程」=找那个 x。
Identity恒等式
含等号，对所有值都成立，常用 ≡。
别混：例 (a+b)²≡a²+2ab+b²。它永远真，不用解。
Inequality不等式
含 < > ≤ ≥，解出的是一个范围。
别混：例 3x+2>8 ⇒ x>2。注意乘除负数变号。
Function函数
一台「机器」：一个输入 x → 唯一一个输出 y，记 y=f(x)，能画成图象。
别混：例 f(x)=3x+2 是整条直线；每个 x 只配一个 y。
最常问：equation 和 function 到底啥区别？
Equation 方程 — 是一个问题：「哪个 x 让式子成立？」——答案是几个数。
2x+1=0 ⇒ x=−½
Function 函数 — 是一种关系/规则：「y 随 x 怎么变？」——是一整条图象。
y=2x+1 是一条直线
桥梁 Link — 解 f(x)=0 = 找函数图象与 x 轴的交点。方程是函数图象上「y=0 那一刻」。
f(x)=2x+1，令 f(x)=0 ⇒ 交 x 轴于 x=−½
代数的分层逻辑：数 Number → 代数式 Expression（用字母表示数）→ 方程 Equation（让两式相等、解 x）→ 函数 Function（把式子当规则、画成图）→ 图象 Graph。它们是同一件事的不同视角：方程 3x+2=8 就是函数 y=3x+2 在 y=8 那条水平线上的交点。

三、几何 & 三角 英文术语

这些概念中文你都会，缺的是英文名——英文卷全靠它读题。不熟的点「✎」记下来。

角的关系 Angles
Complementary angles
余角两角之和 = 90°
Supplementary angles
补角两角之和 = 180°
Adjacent angles
邻角共顶点、共一边
Vertically opposite angles
对顶角两直线相交，正对的一对，相等
Corresponding angles
同位角平行线+截线，同位置，相等（F 形）
Alternate angles
内错角平行线之间交错，相等（Z 形）
Co-interior angles
同旁内角平行线同侧，互补（C/U 形）
Angle bisector
角平分线把一个角平分的线
三角形 Triangles
Interior angle sum
内角和三角形三内角和 = 180°
Exterior angle
外角= 不相邻两内角之和
Interior angle ratio
内角比如内角比 2:3:4，配内角和求各角
Isosceles / Equilateral
等腰 / 等边两边相等 / 三边相等
Scalene / Right-angled
不等边 / 直角三边都不等 / 有一个直角
Hypotenuse
斜边直角三角形对着直角的最长边
Median / Altitude
中线 / 高顶点到对边中点 / 顶点到对边的垂线
Perpendicular bisector
中垂线垂直且平分一条边
Congruent / Similar
全等 / 相似形状大小都同 / 形状同、大小按比例
直线 Lines
Parallel / Perpendicular
平行 / 垂直∥ 永不相交 / ⊥ 成 90°
Transversal
