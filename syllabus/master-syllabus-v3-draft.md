## §1　这版重做的 6 条设计原则

1. **一条主脊，从 0→1。** 先建立"数学的语言与工具"，再打浙教版地基，最后上光剑加料。不再是一堆并列模块。
2. **依赖逻辑优先。** 每个知识点写清 **↑依赖(needs)** 和 **↓解锁(unlocks)**——这是这版最重要的升级。学习顺序由依赖关系决定，不由"文档先后"决定。
3. **浙教版打底 → 加料。** 先把她课本该会的补扎实（很多是"学过但没牢"），再教超纲的光剑技巧。每点标 `浙x上·y` 说明课本在哪、她大概率学过。
4. **几何加全、按依赖排。** 从"点线角"最底层起，一层层：角→三角形→四边形→圆→相似→三角比→坐标几何，每步的前置都写明。这是她最弱、也是光剑第二重的板块。
5. **补三条隐形基础线。** 绝对值、画图(graphing)、集合与逻辑符号——不一定是直接考点，但后面处处要用，各自拉一条从入门到光剑的线。
6. **消除重叠、划清边界。** 例如"因式分解"是独立地基、"一元二次"只管解方程+韦达+判别式，不再各自重讲半个代数。每个知识点只有一个"主人"。
7. **已学·锁定。** 她已学/看完的讲义**原文件一律不改**（她做过一部分了），只在 index 重排分组；要改就**新建版本文件**，绝不覆盖原文件。
8. **定级基于例题难度。** 见 §2——难度锚在真实例题上，不凭感觉、不误判。

标注同时**双语 English-first**（她考英文卷）：每个主题给英文名，术语后续在讲义里配 Key terms。

## §3　学习总路线（跨科顺序 · 先学什么）

> 这是**实际上课顺序**（跨 strand 拉直）。分科的完整逻辑在 §5 起。

**Phase 0 · 数学的语言与工具（地基，everything depends on this）**
数感与负数 → 绝对值(概念) → 坐标系与"怎么画一张图" → 集合与逻辑符号(读题工具) → 代数语言(字母/代数式/代入)

**Phase 1 · 浙教版打底（把课本该会的补扎实）**
代数：整式运算 → 一元一次 → 因式分解 → 分式 → 二次根式 → 一元二次(基础) → 一次/反比例/二次函数(基础) → 不等式(组)
几何：点线角 → 相交线平行线 → 三角形(全等/等腰/勾股) → 四边形 → 圆(基础) → 相似 → 解直角三角形
其他：概率(古典) → 统计(基础)

**Phase 2 · 光剑加料（超纲、真正拉开分的部分）**
代数：韦达+对称式 → 绝对值方程/讨论 → 复合/反函数/函数方程 → 换元与对称因式分解 → 根式裂项/数列/归纳
几何：面积法/将军饮马 → 圆综合(切线/垂径) → 翻折压轴 → 坐标几何综合(反比例+相似/最短路径)
计数：排列组合 → 随机游走概率 → 数论 tricky

**Phase 3 · 竞赛枝 AMC（有余力）**
数论/根号 tricky、新定义与绝对值、逻辑袋鼠、对数入门。

## §4　依赖逻辑总图（strand 之间怎么连）

```
Phase0 语言与工具
   │  (数/绝对值/坐标/集合逻辑/代数语言)
   ├──────────────► 代数 A ──► 函数与图像 C ──┐
   │                   │            │          ├──► 应用与建模 E
   ├──► 几何 B ────────┼────────────┘          │
   │      (坐标系 连通 几何B ↔ 函数C)           │
   └──► 计数·概率·数论 D ───────────────────────┘
                                    ▲
                     加料/竞赛 F（横切，挂在各 strand 顶层）
```

关键连接（"这块为什么必须先学"）：
- **坐标系**是 几何B 与 函数C 的**共用接口**：没有它，坐标几何、画函数图、图象变换全都做不了。
- **因式分解**是 代数A 的枢纽：向下接乘法公式，向上解锁一元二次、分式化简、对称式。
- **相似**是 几何B 的枢纽（光剑×10 最高频）：接全等，解锁面积法、圆综合、坐标几何求值。
- **绝对值 / 画图**两条线贯穿始终：绝对值从"距离"爬到"方程讨论"；画图从"描点"爬到"图象变换/看图求解"。
