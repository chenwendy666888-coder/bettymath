# 数学学习中心 Maths Study Hub

零基础 → 光剑（光华剑桥）入学考 → AMC 枝桠 → 衔接 A-Level 的一套**双语（先英文后中文）**交互式数学讲义与练习。

## 打开方式
- **本地**：双击 `index.html`。
- **GitHub Pages**：仓库 Settings → Pages → Branch: `main` /(root) → 保存，几分钟后用给出的网址访问。
