讲义 02 · 进阶练习

模块 A：一元二次方程与韦达定理（加强版）

00:00

这是加强版。难度重点压在韦达定理及其之后（对称式、代入求参、降次、含参讨论、两根关系）；十字相乘也换成了系数不是 1 的进阶题。共 30 题，建议 75–90 分钟，也可以分两次做（第一、二部分一次，第三、四部分一次）。

做法照旧：先做完一整部分再点开答案，错题打 ✗。

🔑 常用变形速查（做第二、三部分前先看一眼）

  • α² + β² = (α + β)² − 2αβ
  • (α − β)² = (α + β)² − 4αβ
  • α³ + β³ = (α + β)³ − 3αβ(α + β)
  • 1/α + 1/β = (α + β) ⁄ (αβ)　；　α/β + β/α = (α² + β²) ⁄ (αβ)
  • m³ + 1/m³ = (m + 1/m)³ − 3(m + 1/m)
第一部分

十字相乘（系数不是 1）

进阶 约 15 分钟

写成两括号相乘；做完回乘验算。第 6、7 题是双字母。

  1. 3x² + 8x + 4
  2. 4x² − 4x − 3
  3. 6x² − 7x + 2
  4. 6x² + 11x − 10
  5. 8x² + 2x − 3
  6. 6x² + 7xy + 2y²
  7. 3x² − 11xy + 6y²
  8. 10x² − 9x − 9

第一部分答案

  1. (3x + 2)(x + 2)
  2. (2x − 3)(2x + 1)
  3. (2x − 1)(3x − 2)
  4. (2x + 5)(3x − 2)
  5. (2x − 1)(4x + 3)
  6. (2x + y)(3x + 2y)
  7. (x − 3y)(3x − 2y)
  8. (2x − 3)(5x + 3)
第二部分

韦达定理 · 对称式求值

进阶 → 光剑 约 22 分钟

全部用 α+β、αβ 表示后再代入，不要去解根。先写韦达，再套速查表里的变形。

  1. α、β 是 x² − 4x + 2 = 0 的两根，求 α² + β²
  2. α、β 是 x² − 5x + 3 = 0 的两根，求 1/α + 1/β
  3. α、β 是 x² − 5x + 3 = 0 的两根，求 1/α² + 1/β²
  4. α、β 是 x² − 6x + 4 = 0 的两根，求 α/β + β/α
  5. α、β 是 x² − 3x − 5 = 0 的两根，求 (α − β)²
  6. α、β 是 x² + 4x + 1 = 0 的两根，求 α³ + β³
  7. α、β 是 x² − 2x − 1 = 0 的两根，求 α²β + αβ²
  8. α、β 是 x² − 7x + 9 = 0 的两根，求 (α + 1)(β + 1)

第二部分答案

  1. (α+β)² − 2αβ = 16 − 4 = 12
  2. (α+β)/(αβ) = 5/3
  3. = (1/α+1/β)² − 2/(αβ) = (5/3)² − 2/3 = 25/9 − 6/9 = 19/9
  4. = (α²+β²)/(αβ) = (36−8)/4 = 7
  5. (α+β)² − 4αβ = 9 − 4·(−5) = 29
  6. (α+β)³ − 3αβ(α+β) = (−4)³ − 3·1·(−4) = −64 + 12 = −52
  7. αβ(α+β) = (−1)·2 = −2
  8. αβ + (α+β) + 1 = 9 + 7 + 1 = 17
第三部分

代入求参 · 降次

光剑常考 约 22 分钟

代入求参：根代进方程一定成立。降次：用方程本身（如 α² = 3α − 1）把高次一路换成低次。

  1. 方程 x² + mx − 6 = 0 有一个根是 x = 3，求 m 及另一个根
  2. 方程 √3·m·x² − m²·x − 2 = 0 有一个根是 x = 2，求 m² + m⁻²
  3. 已知 m + 1/m = 5，求 m² + 1/m² 及 m³ + 1/m³
  4. α 是 x² − 3x + 1 = 0 的一个根，求 α² + 1/α² 及 α³ + 1/α³
  5. α、β 是 x² − 3x + 1 = 0 的两根，求 α³ + β³ − 2(α² + β²)
  6. α、β 是 x² − 5x + 2 = 0 的两根，求 (α − β)² 及 α³ + β³

第三部分答案

  1. 代 x=3：9+3m−6=0 → m = −1；由 αβ = −6、一根为 3 → 另一根 = −2
  2. 代 x=2 整理得 m² − 2√3 m + 1 = 0 → m + 1/m = 2√3 → (2√3)² − 2 = 10
  3. m² + 1/m² = 25 − 2 = 23；m³+1/m³ = 5³ − 3·5 = 110
  4. 由 α²−3α+1=0 除以 α 得 α + 1/α = 3； α²+1/α² = 9−2 = 7；α³+1/α³ = 27−9 = 18
  5. α³+β³ = 27−9 = 18；α²+β² = 9−2 = 7；18 − 2·7 = 4
  6. (α−β)² = 25 − 8 = 17；α³+β³ = 125 − 3·2·5 = 95
第四部分

含参讨论 · 两根关系

光剑难度 约 28 分钟

当心退化（二次项系数含参数时先讨论它 = 0）；两根关系要把条件翻译成 α+β、αβ 的式子，再和韦达联立；别忘了检查判别式（根要真实存在）。

  1. 关于 x 的方程 (k − 1)x² − 2x + 1 = 0 只有一个实数解，求所有 k
  2. 关于 x 的方程 mx² + (m + 2)x + m = 0 有两个不相等的实数根，求 m 的取值范围
  3. 一元二次方程 x² − 6x + k = 0 的两根都是正数，求 k 的取值范围
  4. 方程 x² − (m + 1)x + 2m − 1 = 0 的两根互为相反数（α = −β），求 m
  5. 方程 x² − m·x + (m − 3) = 0 的两根互为倒数（αβ = 1），求 m
  6. 已知 x² − 3x + 1 = 0 的两根为 α、β，求以 α²、β² 为根的一元二次方程
  7. 一个一元二次方程（首项系数为 1）的两根是 3 + √2 和 3 − √2，求这个方程
  8. 关于 x 的方程 x² − 2(m − 1)x + m² = 0 有两个实数根 α、β，且 α² + β² = 4，求 m

第四部分答案

  1. k=1 时是一次方程 −2x+1=0，一个解 ✓；k≠1 时 Δ=4−4(k−1)=0→k=2。 k = 1 或 2
  2. m≠0 且 Δ=(m+2)²−4m²=−3m²+4m+4>0 → 3m²−4m−4<0 → (3m+2)(m−2)<0。 −2/3 < m < 2 且 m ≠ 0
  3. Δ=36−4k≥0→k≤9；两根之积 = k > 0；和 = 6 > 0 自动满足。 0 < k ≤ 9
  4. α+β=0 → m+1=0。（此时 αβ=2m−1=−3<0，两根确实存在） m = −1
  5. αβ=1 → m−3=1 → m=4。（Δ=16−4=12>0 ✓） m = 4
  6. α²+β²=9−2=7，α²β²=(αβ)²=1 → x² −(α²+β²)x + α²β² = 0。 x² − 7x + 1 = 0
  7. 两根之和=6，之积=(3)²−(√2)²=7。 x² − 6x + 7 = 0
  8. α+β=2(m−1)，αβ=m²；α²+β²=(α+β)²−2αβ=2m²−8m+4=4 → 2m²−8m=0 → m=0 或 4。但需 Δ=4(1−2m)≥0 即 m≤1/2 → m=4 舍去。 m = 0

给家长：这套是模块 A 的拔高，几处最容易失分——

· 第二部分 3、6 题（1/α²+1/β²、α³+β³）：考的是"套对变形公式"，错了就回速查表对一遍；
· 第三部分的降次与"凑 m+1/m"是光剑核心技巧，慢没关系，关键是每步不跳；
· 第四部分三个坑：① 系数含参要讨论退化（第 1 题）；② 求范围别忘判别式（第 2、3 题）；③ 两根关系解完要回代检查根是否真实存在（第 5、8 题就是靠这个筛掉多余答案）。
