Meaning / 意义（距离）

Key terms 关键词
|a| 定义a≥0取a，a<0取−a
distance 距离
|x−a| 意义x到a的距离

IN ENGLISH

|a| strips the sign: |−5|=5. Read as distance: |a| is a's distance from 0, and |x−a| is the distance between x and a.

中文详解

|a| 去符号：|−5|=5。读成距离：|a| 是 a 到 0 的距离，|x−a| 是 x 与 a 的距离。

🟢 低 Basic
|−7|=? → 7
🟡 中 Medium

02

Equations / 绝对值方程（分类）

Key terms 关键词
|x|=b(b≥0)x=±b
|f|=bf=b 或 −b
|f|=g 需 g≥0并验回
cases 分类
IN ENGLISH

|x|=b (b≥0) → x=±b. |f(x)|=g(x) → split f=g or f=−g, need g≥0, so check each root.

中文详解

|x|=b(b≥0)→x=±b。|f|=g→拆 f=g 或 f=−g，需 g≥0，每解代回检验。

🟢 低 Basic
解 |x−3|=2 → x=5 或 1
🟡 中 Medium
解 |2x|=6 → x=3 或 −3
🔴 高 Exam-level（分步展开，先自己想每一步）
解 |2x − 1| = x + 4。
第 1 步 · 右边非负
需 x+4≥0，即 x≥−4。
第 2 步 · 分两类
① 2x−1=x+4→x=5；② 2x−1=−(x+4)→3x=−3→x=−1。
第 3 步 · 验回
x=5:|9|=9✓；x=−1:|−3|=3✓。
✅ 看最终答案 Answer
x=5 或 −1。拆两类后必须回代（g≥0 且成立）。

a>0

IN ENGLISH

For a>0: |x|<a → −a<x<a (middle interval); |x|>a → x<−a or x>a (two ends).

中文详解

a>0：|x|<a → −a<x<a（中间一段）；|x|>a → x<−a 或 x>a（两头）。

🟢 低 Basic
解 |x|<3 → −3
🟡 中 Medium

解 |2x − 1| < 5。
第 1 步 · 用模式
−5<2x−1<5。
第 2 步 · 加1
−4<2x<6。
第 3 步 · 除2
−2

04

Zero-point & distance / 加料：零点分段与几何意义

Key terms 关键词
zero point 零点使某绝对值内为0的x
split 分段
|x−a|+|x−b| 距离和
min=|a−b| 最小值
IN ENGLISH

For |x−1|+|x+2| find zero points (x=1,−2), split the line, remove bars per sign in each piece, solve. Geometrically |x−a|+|x−b| is the total distance to a and b; its minimum is |a−b|, when x is between them.

中文详解

对 |x−1|+|x+2| 找零点(x=1,−2)、把数轴分段，每段按正负去绝对值号再解。几何上 |x−a|+|x−b| 是到 a、b 的距离和，最小值 |a−b|（x 在两者之间时取到）。

🟢 低 Basic
|x−1|+|x−5| 最小值？ → 4（x∈[1,5]取到）
🟡 中 Medium
|x+2|+|x−3| 最小值？ → 5
🔴 高 Exam-level（分步展开，先自己想每一步）
解方程 |x − 1| + |x + 2| = 5。
第 1 步 · 零点分段
零点 1、−2 → 分 x<−2、−2≤x≤1、x>1 三段。
第 2 步 · x≥1 段
(x−1)+(x+2)=5→2x+1=5→x=2 ✓。
第 3 步 · x≤−2 段
−(x−1)−(x+2)=5→−2x−1=5→x=−3 ✓。
第 4 步 · 中间段
(1−x)+(x+2)=3≠5 → 无解。
✅ 看最终答案 Answer
x=2 或 −3。分段→去绝对值→解→查是否落在本段。
