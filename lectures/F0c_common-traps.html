01

Multiply/divide an inequality by a negative → flip / 不等式乘除负数要变号

Key terms 关键词
inequality 不等式<, >, ≤, ≥
multiply/divide by negative 乘除负数reverses order
flip 变号< becomes >
equation vs inequality 方程与不等式only inequalities flip
❌ 错 Wrong−2x < 6 → x < −3
✅ 对 Right−2x < 6 → x > −3　（÷(−2) 时不等号翻向）
IN ENGLISH · WHY

When you multiply or divide both sides of an inequality by a negative number, the inequality flips (< ↔ >). On the number line, multiplying by a negative reflects everything, so the order reverses. Equations never flip — only inequalities. This is the single most common exam slip.

中文·为什么会错

当你把不等式两边同乘或同除一个负数时，不等号要翻向（< 变 >）。在数轴上，乘负数相当于把一切镜像翻转，大小顺序就反了。方程不用变号，只有不等式要。这是考试最常见的失分点。

例 Example

EN: Solve 3 − 2x ≥ 7.

解 3 − 2x ≥ 7。

解: 3−2x≥7 → −2x≥4 → 除以 −2 变号 → x ≤ −2。（若忘记变号会错写成 x≥−2。）

02

(a+b)² is not a²+b² / 完全平方别漏中间项

Key terms 关键词
expand 展开multiply out
cross term 交叉项the 2ab
perfect square 完全平方(a+b)²
FOIL 逐项相乘first, outer, inner, last
❌ 错 Wrong(a+b)² = a² + b²
✅ 对 Right(a+b)² = a² + 2ab + b²　（别漏 2ab）
IN ENGLISH · WHY

(a+b)² = a² + 2ab + b², not a²+b². The middle term 2ab comes from multiplying the two brackets fully: (a+b)(a+b). Forgetting it is extremely common. Quick check with special values: (1+3)² = 16, but 1²+3² = 10 — they differ by 2·1·3 = 6.

中文·为什么会错

(a+b)² = a² + 2ab + b²，不是 a²+b²。中间那项 2ab 来自把两个括号完整相乘 (a+b)(a+b)。漏掉它非常常见。用特殊值秒验：(1+3)²=16，而 1²+3²=10，差的正是 2·1·3=6。

例 Example

EN: Expand (x − 4)².

展开 (x − 4)²。

解: (x−4)² = x² − 2·4·x + 16 = x² − 8x + 16。中间项 −8x 千万别漏。

03

−3² vs (−3)² / 负号在不在括号里

Key terms 关键词
exponent 指数binds tightly
−3²= −(3²) = −9
(−3)²= 9
order 运算顺序power before the minus
❌ 错 Wrong−3² = 9
✅ 对 Right−3² = −9，而 (−3)² = 9
IN ENGLISH · WHY

Without brackets, the power applies only to 3, and the minus is taken afterwards: −3² = −(3²) = −9. With brackets, the minus is inside, so (−3)² = (−3)(−3) = 9. The bracket decides whether the negative is squared.

中文·为什么会错

没有括号时，指数只作用在 3 上，负号最后再加：−3² = −(3²) = −9。有括号时负号在里面，所以 (−3)² = (−3)(−3) = 9。括号决定了负号是否被平方。

例 Example

EN: Evaluate −2⁴ and (−2)⁴.

求 −2⁴ 与 (−2)⁴。

解: −2⁴ = −(2⁴) = −16；(−2)⁴ = 16。差别全在括号。

04

√(a²) = |a|, not a / 开平方得非负

Key terms 关键词
square root √the non-negative root
|a| 绝对值√(a²) = |a|
non-negative 非负result is ≥ 0
sign 符号don't assume a > 0
❌ 错 Wrong√((−5)²) = −5
✅ 对 Right√((−5)²) = |−5| = 5
IN ENGLISH · WHY

The √ symbol always returns the non-negative root. So √(a²) = |a|, not a — because a might be negative. √((−5)²) = √25 = 5, not −5. (Separately, the equation x²=25 has two answers x=±5; but the √ symbol alone means the positive one.)

中文·为什么会错

√ 符号永远取非负根。所以 √(a²) = |a|，不是 a——因为 a 可能是负的。√((−5)²) = √25 = 5，不是 −5。（另外，方程 x²=25 有两个解 x=±5；但单独的 √ 符号只表示正的那个。）

例 Example

EN: Simplify √((x−3)²) for a general x.

化简 √((x−3)²)（x 任意）。

解: = |x−3|，不能直接写成 x−3（当 x<3 时 x−3 为负）。

05

Adding fractions needs a common denominator / 分数相加别分子分母各自加

Key terms 关键词
common denominator 通分same bottom
add tops 分子相加only after same bottom
ab + cd≠ a+cb+d
equivalent 等值rewrite with same bottom
❌ 错 Wrong12 + 13 = 25
✅ 对 Right12 + 13 = 36 + 26 = 56
IN ENGLISH · WHY

You cannot add numerators and denominators separately. First rewrite both fractions with the same denominator, then add the tops. 12 + 13: common bottom 6 → 36 + 26 = 56. (Sanity check: 12 alone is already bigger than 25, so 25 can't be the sum.)

中文·为什么会错

不能把分子、分母各自相加。先把两个分数通分成同一个分母，再把分子相加。12 + 13：通分到 6 → 36 + 26 = 56。（合理性检验：光 12 就已经比 25 大，所以和不可能是 25。）

例 Example

EN: Compute 23 + 14.

计算 23 + 14。

解: 通分到 12：812 + 312 = 1112。

06

Cancel factors, not terms / 约分只能约「乘的公因式」

Key terms 关键词
factor 因式things multiplied
term 项things added/subtracted
cancel 约only common factors
a+bb≠ a
❌ 错 Wronga+bb = a
✅ 对 Righta+bb 不能约（a+b 是相加，不是乘）
IN ENGLISH · WHY

You can only cancel a factor that multiplies the whole top and the whole bottom. You cannot cancel a piece that is added or subtracted. So 2bb = 2 (b is a factor), but a+bb ≠ a (here b is a term added to a). Cross out products, never terms across + or −.

中文·为什么会错

只能约掉乘在整个分子、整个分母上的因式，不能约掉加减里的一项。所以 2bb = 2（b 是因式），但 a+bb ≠ a（这里 b 是与 a 相加的一项）。能划掉的是乘积，绝不是跨着 + − 的项。

例 Example

EN: Simplify 2x+62.

化简 2x+62。

解: 先提公因式：2(x+3)2 = x+3。不能只把一个 2 约掉写成 x+6。

07

Squaring can create false roots / 两边平方要验根

Key terms 关键词
square both sides 两边平方to remove √
extraneous root 增根a false solution
check 验根substitute back
reject 舍根drop the false one
❌ 错 Wrong√x = x−2 → x = 1 或 4（都要）
✅ 对 Rightx = 4（x=1 是增根，代回不成立，舍）
IN ENGLISH · WHY

Squaring both sides can introduce solutions that don't fit the original (because both +k and −k square to k²). After squaring, you must substitute each answer back and reject any that fail. √x = x−2 → x = x²−4x+4 → x=1 or 4; check: x=4 works (√4=2), x=1 fails (√1=−1 is false) → keep only x=4.

中文·为什么会错

两边平方可能造出不满足原方程的解（因为 +k 和 −k 平方都得 k²）。平方后必须把每个答案代回原式，把不成立的舍掉。√x = x−2 → x = x²−4x+4 → x=1 或 4；验根：x=4 成立（√4=2），x=1 不成立（√1=−1 假）→ 只保留 x=4。

例 Example

EN: Solve √(x + 2) = x.

解 √(x + 2) = x。

解: 平方：x+2 = x² → x²−x−2=0 → x=2 或 −1。验根：x=2 成立（√4=2）；x=−1 不成立（√1=−1 假）→ x=2。

08

Dividing by a variable can lose roots / 除以变量当心丢根与除以0

Key terms 关键词
divide by x 除以xassumes x ≠ 0
lost root 丢根x = 0 disappears
factor instead 改用因式分解move all to one side
÷0 除以0undefined
❌ 错 Wrongx² = x → 两边÷x → x = 1
✅ 对 Rightx²−x=0 → x(x−1)=0 → x = 0 或 1
IN ENGLISH · WHY

Dividing both sides by x silently assumes x ≠ 0, so you can lose the solution x = 0. Instead, move everything to one side and factor: x² = x → x²−x = 0 → x(x−1)=0 → x=0 or 1. And you may never divide by 0 — an expression like 1(x−3) is undefined at x=3.

中文·为什么会错

两边除以 x 等于偷偷假设 x ≠ 0，于是会把解 x = 0 弄丢。正确做法是把式子移到一边因式分解：x²=x → x²−x=0 → x(x−1)=0 → x=0 或 1。而且永远不能除以 0——像 1(x−3) 在 x=3 处没有意义。

例 Example

EN: Solve x² = 5x.

解 x² = 5x。

解: 别两边÷x。x²−5x=0 → x(x−5)=0 → x=0 或 5。÷x 会丢掉 x=0。

09

Distribute the minus to every term / 负号要分配到每一项

Key terms 关键词
distribute 分配to each term inside
−(a−b)= −a + b
sign 符号every term flips
bracket 括号minus in front
❌ 错 Wrong−(a − b) = −a − b
✅ 对 Right−(a − b) = −a + b
IN ENGLISH · WHY

A minus sign in front of a bracket flips the sign of every term inside, not just the first. So −(a−b) = −a + b. A very common slip is 5 − (x − 3) = 5 − x − 3; correct is 5 − x + 3.

中文·为什么会错

括号前的负号会把括号里每一项的符号都翻掉，不是只翻第一项。所以 −(a−b) = −a + b。常见错误：5 − (x − 3) = 5 − x − 3；正确是 5 − x + 3。

例 Example

EN: Simplify 8 − (2x − 5).

化简 8 − (2x − 5)。

解: = 8 − 2x + 5 = 13 − 2x。括号里两项符号都要翻。

10

Moving a term flips its sign / 移项要变号

Key terms 关键词
transpose 移项move across =
flip sign 变号+ becomes −
balance 平衡do the same both sides
isolate 分离get x alone
❌ 错 Wrongx + 5 = 2 → x = 2 + 5
✅ 对 Rightx + 5 = 2 → x = 2 − 5 = −3
IN ENGLISH · WHY

Moving a term to the other side of the equals sign flips its sign (it is really “subtract from both sides”). x + 5 = 2 means x = 2 − 5 = −3, not 2 + 5. Check: −3 + 5 = 2 ✓.

中文·为什么会错

把一项移到等号另一边时要变号（本质是「两边同时减」）。x + 5 = 2 应得 x = 2 − 5 = −3，而不是 2 + 5。检验：−3 + 5 = 2 ✓。

例 Example

EN: Solve 3x − 7 = 5.

解 3x − 7 = 5。

解: 移 −7 → 3x = 5 + 7 = 12 → x = 4。移项时 −7 变成 +7。

11

x² = k has two roots / 平方等于常数有两个解

Key terms 关键词
±plus or minus
two roots 两根x = +√k and −√k
don't drop 别漏the negative one
x² = 4x = ±2
❌ 错 Wrongx² = 4 → x = 2
✅ 对 Rightx² = 4 → x = ±2（即 2 或 −2）
IN ENGLISH · WHY

If x² = k (k > 0), there are two solutions: x = +√k and x = −√k, written x = ±√k. Both squared give k. Dropping the negative one loses half the answer. (Note this differs from the √ symbol itself, which means only the positive root.)

中文·为什么会错

若 x² = k（k > 0），有两个解：x = +√k 和 x = −√k，写成 x = ±√k。两个平方都得 k。漏掉负的那个就丢了一半答案。（注意这和 √ 符号本身不同，√ 只表示正根。）

例 Example

EN: Solve (x − 1)² = 9.

解 (x − 1)² = 9。

解: x−1 = ±3 → x = 4 或 −2。两个解都要。

12

+20% then −20% ≠ back to start / 百分比先增后减不回原值

Key terms 关键词
percent of what 基数the base changes
increase 增×(1+p)
decrease 减×(1−p)
net 净变化multiply the factors
❌ 错 Wrong+20% 再 −20% → 回到原价
✅ 对 Right×1.2×0.8 = 0.96 → 比原来少 4%
IN ENGLISH · WHY

A percent is a percent of the current amount, and that amount changes. Rising 20% then falling 20% is ×1.2 then ×0.8 = ×0.96, i.e. 4% below the start — because the 20% drop is taken from the larger, raised amount. Percents don't simply add or cancel.

中文·为什么会错

百分比是对「当前的量」取的百分比，而这个量在变。先涨 20% 再跌 20% 是 ×1.2 再 ×0.8 = ×0.96，即比原来少 4%——因为那 20% 的跌是从涨高后的更大数上扣的。百分比不能简单相加或抵消。

例 Example

EN: A $100 item rises 10%, then falls 10%. Final price?

一件 100 元的商品先涨 10%、再跌 10%，最后多少钱？

解: 100×1.1×0.9 = 100×0.99 = 99 元，比原来少 1%。
