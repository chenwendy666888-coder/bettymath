What this covers / 这一章要学什么

Key terms 关键词
intersecting lines 相交线交于一点的两直线
parallel lines 平行线永不相交，记 a∥b
transversal 截线截两条直线的第三条
angle pair 角的关系相等或互补
IN ENGLISH

When two lines cross, they make angle pairs that are either equal (vertical angles) or add to 180° (adjacent). When a third line cuts across two lines, it makes the famous eight angles — and if the two lines are parallel, these angles obey clean rules you can use to find unknown angles and to prove lines parallel. This chapter is the grammar of almost every geometry problem.

中文详解

两条直线相交时，产生的角要么相等（对顶角），要么互补（邻补角）。当第三条线截过两条直线时，就出现著名的「三线八角」——而如果那两条线平行，这些角就遵守漂亮的规则，可以用来求未知角、也可以用来证明两线平行。这一章是几乎所有几何题的语法。

01

Vertical & adjacent angles / 对顶角与邻补角

Key terms 关键词
vertical angles 对顶角相对的一对，相等
adjacent supplementary 邻补角相邻的一对，和180°
∠1 = ∠3 对顶相等
∠1 + ∠2 = 180° 邻补互补
IN ENGLISH

Two crossing lines make four angles. The two opposite ones are vertical angles and are always equal (∠1 = ∠3). Two neighbouring ones sit on a straight line, so they are adjacent supplementary and add to 180° (∠1 + ∠2 = 180°). Know one angle and you know all four.

中文详解

两条相交直线形成四个角。相对的两个是对顶角，永远相等（∠1 = ∠3）；相邻的两个在一条直线上，是邻补角，和为 180°（∠1 + ∠2 = 180°）。知道一个角，四个角全知道。

🟢 低 Basic
两直线相交，∠1 = 50°，它的对顶角 = ? → 50°（对顶角相等）
🟡 中 Medium
∠1 = 50°，它的邻补角 = ? → 180° − 50° = 130°
🔴 高 Exam-level（分步展开，先自己想每一步）
两条直线相交，其中一个角比它的邻补角大 40°，求这两个角。
第 1 步 · 设角与邻补角
设这个角为 x，则它的邻补角为 180° − x。
第 2 步 · 「大 40°」列方程
x = (180 − x) + 40。
第 3 步 · 解方程
x = 220 − x → 2x = 220 → x = 110°，邻补角 = 70°。
✅ 看最终答案 Answer
两个角是 110° 和 70°。检验：110 + 70 = 180、差 40 ✓。相交线问题几乎都靠「对顶相等 + 邻补互补」列方程。
02

Perpendicular & distance / 垂线与点到直线的距离

Key terms 关键词
perpendicular 垂直成 90°，记 ⊥
foot 垂足垂线与直线的交点
perpendicular segment 垂线段从点到直线最短的连线
distance 点到直线的距离即垂线段的长
IN ENGLISH

If two lines meet at 90° they are perpendicular (⊥). From a point off a line, the perpendicular segment (straight down to the line) is shorter than any slanted segment — so the distance from a point to a line is the length of that perpendicular segment. Through a point there is exactly one perpendicular to a given line.

中文详解

若两条线相交成 90°，就互相垂直（⊥）。从直线外一点向直线所作的垂线段（直直落到直线上），比任何斜线段都短——所以点到直线的距离，就是这条垂线段的长。过一点，向一条直线只能作一条垂线。

🟢 低 Basic
PA ⊥ l 于 A，PA = 5，PB 是斜线，PB 与 5 谁大？ → PB > 5（垂线段最短）
🟡 中 Medium
点 P 到直线 l 的距离指的是哪条线段？ → 过 P 作 l 的垂线段（PA）的长
🔴 高 Exam-level（分步展开，先自己想每一步）
P 到直线 l 的距离是 4。直线上有 A、B 两点，PA = 5，PB = 4，问 A、B 哪个是垂足？PA 是垂线段还是斜线？
第 1 步 · 距离 = 最短 = 垂线段
点到直线的距离 4，就是那条垂线段的长；垂线段是所有连线里最短的。
第 2 步 · 谁等于 4 谁就是垂线段
PB = 4 = 距离 → PB 是垂线段，B 是垂足。
第 3 步 · PA 呢
PA = 5 > 4，是斜线段（比垂线段长，符合「垂线段最短」）。
✅ 看最终答案 Answer
B 是垂足，PB 是垂线段；PA 是斜线段。等于「距离」的那条就是垂线段，其余都更长。
03

A transversal: the eight angles / 三线八角

Key terms 关键词
corresponding 同位角同侧同位（F 形）
alternate interior 内错角内侧两旁（Z 形）
co-interior 同旁内角内侧同旁（U 形）
interior 内侧两线之间
IN ENGLISH

When a transversal cuts two lines it makes 8 angles. Three pairs matter: corresponding angles (同位角) — same position at each crossing (an F shape); alternate interior angles (内错角) — between the lines, on opposite sides (a Z shape); co-interior / same-side interior angles (同旁内角) — between the lines, on the same side (a U shape). Learn to spot F, Z, U.

中文详解

一条截线截两条直线，形成 8 个角。要记住三对：同位角——在每个交点的相同位置（像 F 形）；内错角——在两线之间、分居两旁（像 Z 形）；同旁内角——在两线之间、同一旁（像 U 形）。练到一眼认出 F、Z、U。

🟢 低 Basic
图中 ∠1 与 ∠5 是什么关系角？ → 同位角（相同位置，F 形）
🟡 中 Medium
∠3 与 ∠5（两线之间、分两旁）是什么角？ → 内错角（Z 形）
🔴 高 Exam-level（分步展开，先自己想每一步）
用图中编号说出：哪对是同位角、哪对是内错角、哪对是同旁内角各举一例，并说明「内侧」指哪里。
第 1 步 · 认「内侧」
两条被截直线之间的区域是内侧（∠3、∠4、∠5、∠6 在内侧）。
第 2 步 · 同位角(相同位置)
例如 ∠1 与 ∠5、∠2 与 ∠6、∠4 与 ∠8：在两个交点的相同角位（F 形）。
第 3 步 · 内错角(内侧、两旁)
例如 ∠3 与 ∠6、∠4 与 ∠5：都在内侧、分居截线两旁（Z 形）。
第 4 步 · 同旁内角(内侧、同旁)
例如 ∠3 与 ∠5、∠4 与 ∠6：都在内侧、且在截线同一旁（U 形）。
✅ 看最终答案 Answer
同位 ∠1&∠5；内错 ∠4&∠5；同旁内 ∠3&∠5。先分清「内/外」和「同旁/两旁」，三种角就不会混。
04

Proving lines parallel / 平行线的判定

Key terms 关键词
parallel 平行a∥b，永不相交
corresponding equal → ∥ 同位角相等
alt-interior equal → ∥ 内错角相等
co-interior supp → ∥ 同旁内角互补
IN ENGLISH

To prove two lines are parallel, show any one of: corresponding angles equal, or alternate interior angles equal, or co-interior angles supplementary (sum 180°). Any one is enough — pick whichever pair the figure hands you.

中文详解

要证明两条直线平行，只需说明下面任意一条：同位角相等，或内错角相等，或同旁内角互补（和 180°）。任意一条成立即可——图里给你哪对角，就用哪条。

🟢 低 Basic
若同位角 ∠1 = ∠2，能得到什么？ → a ∥ b（同位角相等，两直线平行）
🟡 中 Medium
若内错角相等（都 = 65°），两线平行吗？ → 平行（内错角相等 → 平行）
🔴 高 Exam-level（分步展开，先自己想每一步）
一条截线截 a、b，同旁内角分别是 2x° 与 (3x + 20)°。当 x 为何值时 a ∥ b？
第 1 步 · 选判定
要 a∥b，用「同旁内角互补」：两角之和 = 180°。
第 2 步 · 列方程
2x + (3x + 20) = 180。
第 3 步 · 解
5x + 20 = 180 → 5x = 160 → x = 32。
✅ 看最终答案 Answer
x = 32°（此时两同旁内角 64°、116°，和 180° → a∥b）。判定是「由角相等/互补 推出 平行」。
05

Properties of parallel lines / 平行线的性质

Key terms 关键词
given a∥b 已知平行
corresponding equal 同位角相等
alt-interior equal 内错角相等
co-interior supp 同旁内角互补
IN ENGLISH

This is the reverse of the last section. Once you know a∥b, the angles obey: corresponding angles equal, alternate interior angles equal, and co-interior angles supplementary. Use these to find unknown angles. (Judgment: angles → parallel. Property: parallel → angles.)

中文详解

这是上一节的反过来。一旦知道 a∥b，角就满足：同位角相等、内错角相等、同旁内角互补。用它们来求未知角。（判定：由角 → 平行；性质：由平行 → 角。方向别弄反。）

🟢 低 Basic
a∥b，一个同位角 = 70°，另一同位角 = ? → 70°（同位角相等）
🟡 中 Medium
a∥b，某内错角 = 70°，与它同旁的同旁内角 = ? → 180° − 70° = 110°（同旁内角互补）
🔴 高 Exam-level（分步展开，先自己想每一步）
a∥b，被一条截线所截。一对内错角是 (2x + 10)° 与 (3x − 20)°，求 x 及这对角的度数。
第 1 步 · 用性质
a∥b → 内错角相等 → 2x + 10 = 3x − 20。
第 2 步 · 解
10 + 20 = 3x − 2x → x = 30。
第 3 步 · 求角
2x + 10 = 70°（两个都 70°）。
✅ 看最终答案 Answer
x = 30，这对内错角都是 70°。已知平行就「同位/内错相等、同旁内互补」，直接列方程。
06

The kink point / 拐点问题（作辅助平行线）

Key terms 关键词
auxiliary line 辅助线为解题补画的线
draw a parallel 作平行线过拐点作平行于已知线
split the angle 拆角把折角拆成两个错角
AB∥CD 已知两线平行
IN ENGLISH

When two parallels have a kink point E between them (a Z-shaped bend), the trick is to draw a line through E parallel to both. This splits the bent angle ∠AEC into two alternate interior angles, so ∠AEC = ∠BAE + ∠DCE. One auxiliary line turns a scary figure into two easy ones.

中文详解

当两条平行线之间有一个拐点 E（Z 字形折角）时，诀窍是过 E 作一条与两线都平行的线。它把折角 ∠AEC 拆成两个内错角，于是 ∠AEC = ∠BAE + ∠DCE。一条辅助线，把吓人的图变成两个简单的图。

🟢 低 Basic
拐点问题里，最关键的一步辅助线是什么？ → 过拐点 E 作一条平行于 AB、CD 的线
🟡 中 Medium
AB∥CD，∠BAE = 35°，∠DCE = 25°，∠AEC = ? → 35° + 25° = 60°
🔴 高 Exam-level（分步展开，先自己想每一步）
AB∥CD，点 E 在两平行线之间，∠BAE = 40°，∠DCE = 30°，求 ∠AEC。
第 1 步 · 作辅助线
过 E 作 EF ∥ AB（则也 ∥ CD，因为 AB∥CD）。
第 2 步 · 上半：内错角
EF∥AB → ∠AEF = ∠BAE = 40°（内错角相等）。
第 3 步 · 下半：内错角
EF∥CD → ∠CEF = ∠DCE = 30°（内错角相等）。
第 4 步 · 合起来
∠AEC = ∠AEF + ∠CEF = 40° + 30° = 70°。
✅ 看最终答案 Answer
∠AEC = 70°。记住结论 ∠AEC = ∠BAE + ∠DCE，但要会用「过拐点作平行线 + 内错角」推出来。

练习 Practice

只做题、不给提示——先自己想；不会的点右下角「🙋 我没懂」。带【同型·卷】的是光剑/他校题的改编同型题。

基础 Basic

  1. 两直线相交，∠1 = 63°，求它的对顶角与邻补角。 / vertical & adjacent.
  2. PA⊥l 于 A，PA=6，直线上另取一点 B，PB 与 6 谁大？为什么？ / compare.
  3. 图中截两线成八角，写出 ∠2 的同位角、内错角、同旁内角各一个。 / name pairs.
  4. a∥b，一个同位角是 118°，求它的内错角与同旁内角。 / find angles.

进阶 Intermediate

  1. 两直线相交，一个角是它邻补角的 2 倍，求这两个角。 / one is twice its supplement.
  2. 【判定】截线截 a、b，同旁内角为 (3x) 与 (2x+30)，x 为何值时 a∥b？ / find x for parallel.
  3. 【性质】a∥b，一对内错角为 (4x−10) 与 (2x+30)，求 x 与角度。 / find x & angle.
  4. AB∥CD，∠BAE=55°，∠DCE=20°，E 在两线间，求 ∠AEC。 / kink point.

挑战 Challenge

  1. 【挑战·多拐点】AB∥CD，折线 A–E–F–C 有两个拐点，∠A=30°，∠F… 设 ∠AEF=x、∠EFC=y，探究 ∠A、∠C 与 x、y 的关系。 / two kinks (open exploration).
  2. 【挑战·判定+性质】截线截 a、b，∠1（a 上）与 ∠2（b 上）为内错角，∠1=2∠2−30，且 a∥b，求 ∠1。 / combine.
  3. 【挑战·垂直】∠AOB=90°，OC 平分∠AOB，OD⊥OC，求 ∠AOD 的可能值。 / cases.
  4. 【挑战·代数】两直线相交成四个角，其中一个角的度数是相邻角的 23，求这个角。 / one is 2/3 of its neighbour.
